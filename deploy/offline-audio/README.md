# 离线陪伴音频部署目录

将已经取得使用授权的中文陪伴语音放到板端：

```text
/home/longpet/offline-audio
```

当前支持由 GStreamer 自动解码的 `.wav`、`.mp3`、`.ogg`、`.flac` 文件。建议使用
16 kHz 或 48 kHz、单声道 WAV，以减少板端解码开销。文件名没有业务含义；程序会随机选择，
并在存在两条以上音频时避免连续两次播放同一条。

仓库不附带录音，以免把未经确认授权或不符合比赛要求的声音资源提交进 Git。目录为空、
文件不可读或播放失败时，LongPet 只显示简短错误，KWS 和 UI 按钮仍可继续使用。
